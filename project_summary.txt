**2. Authentication Flow**
- Local signup/login lives in `backend/controllers/user.controller.js`.
- Google login lives in `backend/controllers/google.authcontroller.js`.
- Login creates a JWT using `SECRET_KEY`.
- JWT is stored in an HTTP-only cookie named `token`.
- `isAuthenticated` reads the cookie, verifies JWT, and sets `req.id = decoded.userId`.
- Frontend stores the returned user in Redux `auth.user`, persisted via `redux-persist`.
- Protected frontend routes use `components/admin/protectedroute.jsx`.

**3. User Model**
`User` contains:
- `fullname`, `email`, `phoneNumber`, `password`, `role`
- `authProvider`, `googleId`, `isProfileComplete`
- `profile` object with:
  - `bio`, `skills`
  - links: `github`, `linkedin`, `portfolio`

Resume data is already stored under `user.profile`, so the AI feature can read from there without changing the model.

There is no `skills` or `industry` field currently, so matching should use existing fields and conditionally include optional fields only if present.

**5. Resume Upload Flow**
Resume upload happens during:
- register
- complete profile
- profile update

Flow:
- Multer memory storage receives file.
- File is converted to DataURI.
- Uploaded to Cloudinary as `resource_type: "raw"`.
- User profile stores:
  - `profile.resume` as Cloudinary `public_id`
  - `profile.resumeUrl` as Cloudinary secure URL
  - `profile.resumeOriginalName`

Important: multer currently allows PDF, DOC, and DOCX resumes. The requested AI flow specifically says extract PDF text using `pdf-parse`, so non-PDF resumes should return a clean “PDF parsing failed / unsupported resume format” style error instead of crashing.

**11. Redux Architecture**
- Store uses Redux Toolkit.
- Root reducer combines:
  - `auth`
  - `job`
  - `company`
  - `application`
- `redux-persist` persists the root reducer.
- `auth` also has its own persist config with `loading` blacklisted.
- `authslice` stores `loading` and `user`.
- `jobslice` stores all jobs, admin jobs, single job, applied jobs, and search terms.
- The AI resume feature does not need Redux. Local component state is better because scan results are request-specific and should not alter existing global job state.
